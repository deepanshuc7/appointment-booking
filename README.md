# Appointment Booking System

A full-stack appointment booking system for a single service provider.

## Applications

- `customer-web` — Customer-facing booking application
- `provider-web` — Service provider dashboard
- `api` — Hono API running on Bun

## Tech Stack

- React
- TypeScript
- TanStack Router
- TanStack Query
- TanStack Form
- Hono
- Bun
- PostgreSQL
- Drizzle ORM
- Zod
